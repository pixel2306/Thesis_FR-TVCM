# Functional Regression Time Varying Coefficient Model (FR-TVCM)

The FR-TVCM extends the varying-coefficient model of Hastie and Tibshirani to functional responses.
The Model is represent as below

$$Y_i(t) = \beta_0(t)+Y_{i-1}(t)\beta_1(t) + ... + Y_{i-p}(t)\beta_p(t) + \varepsilon_i(t) $$

where

$$Y_i(t)$$ = load curve of day i

$$\beta_i(t)$$ = coefficient function of day i

$$\varepsilon_i(t)$$ = residual process of day i
